# Security policy

OriginRAG is designed for local or SSH-tunnelled use. Do not expose the built-in
Python web server directly to the public internet.

Report ordinary bugs through GitHub Issues. For a vulnerability that could
expose credentials, local papers, generated answers, or account data, use the
repository's private vulnerability-reporting channel when available. If that
channel is unavailable, contact the maintainer privately through the GitHub
profile and do not publish exploit details until a fix is available.

Please include the affected version, operating system, deployment mode, and a
minimal reproduction that contains no private papers, credentials, or user
data.
