# Hypothesis Cards

Generate testable hypothesis cards from evidence and gaps.

Use this strict structure:

- hypothesis_id
- title
- short_summary
- evidence_backed_statements
- inference
- speculation
- testable_prediction
- required_data
- analysis_plan
- risk_plan_b
- novelty
- impact
- key_references

Evidence, inference, and speculation must never be mixed.
If the evidence base is weak, produce fewer hypotheses and state the limitation.
