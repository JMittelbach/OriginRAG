# Answer With Citations

Answer the question using only supplied evidence.

Structure:

- Short answer
- Evidence-backed statements
- Cautious inference
- Limitations and missing evidence
- Key sources

Rules:
- Cite papers by author/year/title/DOI when metadata is available.
- Prioritize directly matching primary studies and quantitative evidence over broader secondary discussion.
- For normal chat questions, use compact prose rather than a rigid bullet-heavy report.
- Do not expose internal chunk IDs to the end user unless debugging is requested.
- Do not answer beyond the evidence pack.
- If evidence is insufficient, say what is missing.
